# Why the local checkpoint replay is numerically sensitive

The previously identified worst local GPU discrepancy is explained *at the final hyperbolic map* by a one-step float32 difference very close to the boundary. For origin **186 / ADBE**, the CPU and GPU scalar inputs to the final map were **0.9999783039** and **0.9999783635**—a difference of **5.96×10⁻⁸**. Applying the same scalar map to those two values in float64 gives a difference of **0.00137553**; the actual CPU-versus-GPU model base output differs by **0.00137568**. The map's local unclipped derivative at the larger radius is about **23,109**, so it magnifies tiny endpoint differences substantially.

The final saved-forecast error for this cell is **0.00151825 percentage points**, above the unchanged **0.000001-point** acceptance threshold. The base-output and final forecast errors are different quantities: the remaining mixer and auxiliary path lie downstream. This identifies a concrete amplification mechanism on the local hardware, but it does **not** prove why the published original-device output differs, reproduce the full checkpoint, or justify widening the gate.

Empty radius bands are omitted from `BANDS.csv`. No eligible endpoints in this batch reach the map's 0.99999 projection cap; the derivative quoted above is the applicable unclipped scalar derivative for the reference.

The local GPU's full batch scores and three hooked layers exactly match the previous local GPU trace, and a repeat GPU call is bit-identical. `CELLS.csv` and `ENDPOINTS.npz` preserve all eligible values and axes; hashes and the local environment are in `RESULTS.json`. An independent scalar reconstruction verified all 714 cells and their radius-band summaries within 2.23e-16; two scalar-map tests passed. This is a **numerical reproduction diagnostic**, not a feature ablation, peer-information test or financial-result claim. It uses the original trained weights without changing their inputs or source, on the already inspected test batch; CPU64 is an additional mathematical comparison, not the original execution contract.
