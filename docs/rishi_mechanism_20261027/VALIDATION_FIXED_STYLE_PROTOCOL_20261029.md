# Fixed validation preference and as-of stock characteristics

Frozen after batches46–56, before these correlations. Reconstruct the same per-stock validation blend mean percentile ranks for all three seed groups and four annual folds, with at least five eligible validation origins. At each fold's first test origin, use only that origin's eligible names with finite preference and finite stock characteristic. Compare preference against four fixed as-of characteristics: trailing QQQ beta (up to 252 days, 126 valid minimum), 126-session price momentum with valid endpoints, 20-session volatility (15 valid minimum), and log10 20-session average dollar volume, using the already established `asof_style` definitions. Compute 48 group/year/feature Spearman correlations with average ties, retain each supporting stock row, sample counts and all input hashes. Independently recompute each coefficient and support from the saved stock rows. No labels, future test-period scores, account scoring, neural inference or fitting.

All correlations are descriptive, unadjusted and post-outcome on inspected history, not causal effects or measures of information value. Each characteristic has its own support and is not a controlled regression; years and seed groups are not independent market replications. Validation selected checkpoints, so these are not training Hpred or validated stock intercepts. Source data vintage, security identity and original numerical gates remain unchanged.
