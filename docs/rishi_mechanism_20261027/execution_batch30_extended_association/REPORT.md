# Saved rankings and extended-hours input associations

The saved dynamic-model rankings show a relationship with **extended-hours coverage** that varies sharply across the four annual folds: negative in 2022, close to zero in 2023, and positive in 2024–2025. Their relationship with the latest after-hours and premarket **returns** is comparatively small in these same raw cross-sectional summaries. This is a clue about the behavior of the rankings, not proof that the model used coverage causally or that coverage generated returns.

Protocol 686838f and code 4ca0849 were fixed before measurement. We compared ten-seed saved parent (B), dynamic (D), blend (E), and training-label preference (Hlabel) ranks with the latest raw after-hours and premarket return and coverage features, at each of 201 original NDX decision origins. Each origin/feature uses only original eligible names with finite observed values; score and feature ranks use the same support and average ties. The following are equal-origin-weighted **mean cross-sectional Spearman correlations**, not return correlations or independent market replications:

| Fold | B AH coverage | D AH coverage | B PM coverage | D PM coverage | B AH return | D AH return | B PM return | D PM return |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 2022 | .244 | -.127 | .257 | -.158 | -.016 | -.012 | -.055 | .032 |
| 2023 | .081 | .099 | .094 | .085 | -.025 | -.031 | -.002 | .043 |
| 2024 | .070 | .253 | .072 | .249 | -.005 | -.008 | .008 | .047 |
| 2025 | .089 | .358 | .101 | .302 | .008 | -.001 | -.004 | -.033 |

Coverage correlations use approximately 101 eligible names per origin on average; AH returns use 50–62 and PM returns 45–60, depending on the fold. Thus the return and coverage columns do **not** describe identical stock subsets. The data source leaves numeric features missing when too few bars are observed; coverage is observed activity, not certified vendor completeness. PM return excludes the prior-close gap, and is aligned to the following exchange session; actual first-publication timing is not independently certified. All 3,216 fixed origin/model/feature cells, support counts, eligible counts and undefined values are retained in `PER_ORIGIN.csv`; all four models and centered/raw annual summaries are in `ANNUAL.csv`. No p-values or winner selection are implied.

As a separate retrospective sensitivity, we subtracted each security's *whole test-fold* mean rank from both score and feature ranks before calculating within-origin correlations. For dynamic versus AH coverage, annual means become **-.159, -.036, -.094, +.122**; for dynamic versus PM coverage they become **-.118, +.030, -.068, +.077**. This weakens or reverses some raw associations, consistent with persistent cross-sectional differences contributing to them, but does not isolate a learned identity effect. Cross-sectional ranks and eligible supports change over time, and this centering uses later test observations; it is descriptive, nontradable, and not the missing training-only Hpred control.

Association is not sensitivity to a feature intervention. A coverage relationship could reflect stock identity, liquidity, sector, correlated price features, selection into observed data, or other common drivers. The four years and origins share dependent market histories, and this is heavily inspected development data. A larger coverage correlation cannot establish whether the model learned a useful activity signal or whether it explains P&L; the trained-checkpoint and temporal-provenance gates remain unchanged. The results prioritize matched coverage-versus-price interventions once those gates permit them.

Independent reconstruction checked all 3,216 correlations and 247,028 per-stock rank rows, with maximum raw and centered numerical discrepancies 3.34e-16 and 1.93e-14. A separate spot check reconstructed raw input and saved-score ranks for 48 origin/model/feature cells. Two focused tests passed. `RESULTS.json` records hashes of the feature cube, timing, scores, reviewed panel inputs and code; the launcher code hash refers to a temporary compatibility copy. No model inference, realized-label analysis, account scoring, new model fitting or protected S&P scoring occurred.
