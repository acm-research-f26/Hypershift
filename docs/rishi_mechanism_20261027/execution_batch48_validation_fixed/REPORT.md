# Fixed validation preferences versus weekly test selections

For each fold, this diagnostic freezes each stock's mean validation blend rank and applies it to the stocks eligible at each later test decision. The ten-seed fixed-preference target shares an average of **2.02, 4.06, 3.90 and 3.64 securities** with the actual issuer-five model target across the 2022–2025 test folds. Average target-weight overlap is **40.4%, 81.2%, 78.0% and 72.8%**, respectively. Equal target weights and ties make the weight and name measures related but not identical. Original-five and new-five annual results, plus every decision row, are in `ORIGINS.csv`.

This is a more decision-aligned stability check than comparing full-year test averages: the fixed preference comes from the preceding validation period and the comparison uses each decision's actual eligibility. It still does not measure returns, isolate model components or prove that a fixed-preference portfolio would be as good. Validation selected the checkpoints, and the study period has been repeatedly inspected. The original-five, new-five and ten-seed groups share a market history. Newly eligible securities lacking at least five validation observations receive the qualifying cross-security median; no fallback security was selected in any of the 603 fixed targets, although fallback securities remained eligible.

Protocol `9e19776` was frozen after the earlier rank results but before this comparison. Eighty saved forecast files were hashed. A separately written pandas and issuer-boundary-tie reconstruction checked all **603** target comparisons and matched every overlap exactly. The original five-issuer saved allocations, not actual broker fills, are the comparator. No test labels, account simulation, model fitting or checkpoint inference were used; the training Hpred and strict checkpoint gates remain unchanged.
