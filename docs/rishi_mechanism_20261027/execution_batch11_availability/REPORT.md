## Which membership states contributed?

Consecutive current-membership age uses only the source-panel prefix, resetting on reentry. Three states partition each day's recorded economic gross P&L and fees: outside current snapshot; current member for 1–126 sessions; established member. This is not IPO age. Initial membership history is left-censored, snapshots are retrospective source reconstructions, and class attribution is descriptive rather than a newly traded exclusion policy.
