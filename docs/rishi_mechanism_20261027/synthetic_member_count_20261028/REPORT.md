# Synthetic membership and replication checks

Protocol ../MEMBER_COUNT_TOY_PROTOCOL.md (f2a8b93) and implementation 8c97321 were fixed before this run. These are **randomly initialized**, eight-node synthetic models, not original trained financial checkpoints. Three model seeds and three synthetic input cases were tested at 2, 4, 6 and 8 active IDs for both diverse and artificially replicated peer inputs. Each configuration was evaluated through the full architecture and the existing temporal-only path: 144 path cells total.

Across the 108 cells with at least one inactive ID, replacing inactive inputs with zeros, NaNs or large finite values left all eligible predictions and the input gradient of the **sum of eligible predictions** exactly equal. All tested gradients for that scalar objective were finite, and its maximum inactive-input gradient was zero. This is not a full per-output Jacobian or a parameter-gradient test. The 36 all-active cells are explicitly **not applicable** to the inactive-input test. These checks support masking within these cases, not a proof for all inputs, all membership transitions or the financial checkpoints.

Changing active count from 2 to 8 changed the focal stock's output in the full architecture by up to **0.02381 synthetic score units** across the fixed seeds, cases and populations. The temporal-only path's focal output was unchanged in this setup. Replicating the same peer into more active slots also produced count sensitivity in the full path; at eight active IDs its absolute focal change ranged from 0.000325 to 0.02337. The largest focal difference between diverse and replicated peers at the same count was 0.00620. These are fixed-eight-slot population experiments: the graph and stock-indexed positions remain in place. The full path includes both learned-incidence and static-snapshot machinery, so this does not isolate either component, establish an implementation error, demonstrate useful financial information, or quantify a return effect. Aggregate and signed per-cell values are in CELLS.csv.

An independent check verified the 144 unique cells, 108 applicable masking cases, 36 non-applicable all-active cells, baseline arithmetic and zero inactive gradients for the summed-output objective. Independent conceptual review found no substantive blocker and prompted the objective-specific gradient clarification. Eight focused tests passed. RESULTS.json and VALIDATION.json record source hashes and checks. No financial data, trained model, optimizer, protected window or checkpoint tolerance was used.
