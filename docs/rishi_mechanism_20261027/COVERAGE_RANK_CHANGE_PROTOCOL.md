# Consecutive-origin score and coverage rank changes — 2026-10-28

This exploratory follow-up is frozen after batches 30–32 and before its measurements. For all 2022–2025 folds, fixed B/D/E/Hlabel ten-seed saved rank rows and AH/PM coverage, compare each original decision origin with the immediately preceding origin **in the same fold**. Intersect security IDs present on both origins, original eligibility and finite coverage/score. Use each original batch30 eligible-support percentile rank and calculate later minus earlier score-rank and coverage-rank changes per ID. Also calculate later minus earlier log 20-session ADV at the two corresponding prior regular closes from the reviewed panel; exclude missing or nonpositive ADV from both comparisons. No future labels, outcomes, portfolio changes, checkpoint inference or financial fitting.

For each of 197 within-fold adjacent-origin pairs × four models × two segments (1,576 cells), compute Spearman correlation between score-rank changes and coverage-rank changes on the matched IDs, and the partial correlation of their average ranks after OLS residualization on an intercept plus ranked ADV change. Require at least 20 paired IDs, nonconstant variables, nondegenerate residuals and full-rank controls; otherwise retain an undefined value and reason. Report paired-ID support and drop counts, all cells, fold-level equal-pair mean/median and defined counts, and lag length in sessions. The label-mean Hlabel comparison helps reveal rank changes induced by changing cross-sectional membership, not a static absolute benchmark. Independently recompute numerical results and hash inputs.

This avoids future-within-fold centering and tests whether observed changes co-move, but it is still descriptive and selected-history. Percentile ranks can change when other securities change or membership changes even if a stock's score or coverage is unchanged; limiting to paired IDs does not fix this. ADV and extended-hour coverage can be jointly affected by activity; partial correlation is not causal adjustment. Source timestamps do not certify provider first publication; raw intraday bars and actual learned feature sensitivities remain unavailable. No performance, alpha, feature-causality or confirmation claim, and no change to checkpoint or financial-training gates.
