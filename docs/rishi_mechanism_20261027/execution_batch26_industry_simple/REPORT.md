# Sparse industry-matched simple-signal controls

The protocol ../INDUSTRY_SIMPLE_SIGNAL_PROTOCOL.md (a6dd2ca) and implementation ef7115f were fixed before scoring. At each original E or E_Hlabel top10 decision, each control preserves the exact FF12/unknown group target budgets, positive-position count and weight multiset. It assigns those weights to eligible names in each group using one previously exported simple score: training-label mean Hlabel, five-session reversal, 126-session momentum, or the previously fitted training-only ridge. Exact score ties use a predeclared fixed priority, rather than the source engine's fractional tie allocation. All decisions inherit the model's changing industry and position-size schedule.
