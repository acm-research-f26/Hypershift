# Fixed-validation account gross/fee decomposition

Frozen after batch49 account and turnover results, before computing this decomposition. For all six fixed group/policy pairs, use the existing reconciled ledgers and paths, without rerunning accounts. Per day divide modeled trading fee dollars by that account's preceding NAV; define accounting gross contribution as saved net return plus this fee fraction, preserving the actual fee-affected holdings and path. Verify each ledger's NAV, fee and return axes, and exact daily identities. Compare original minus fixed annual arithmetic net, gross and fee drag; report all annual fold partitions, mean exposure and annualized turnover, and synchronized 21-session stationary-bootstrap 95% intervals for each component using 10,000 draws and seed 27102030. The fee difference enters net with opposite sign. Record all six pairs and input hashes. Independently reconstruct the 18 component intervals and ledger identities. No new model or account is fit or scored, and no changed-fee counterfactual is implied.

This is post-outcome accounting on selected historical development data, with overlapping seed groups. Gross contributions retain fee-influenced holdings and NAV; they are not the outcome of a zero-cost trading simulation. Different baskets and exposure processes confound the comparison. Results do not establish causal model information, Hpred, equivalence, prospective performance or a gate change.
