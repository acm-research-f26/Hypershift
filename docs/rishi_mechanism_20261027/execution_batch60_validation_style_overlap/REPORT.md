# Do simple style rankings select the validation favorites?

For the ten-seed fixed-validation preference, a ranking based only on **pretest 20-day dollar volume** overlaps its five-issuer targets by an average of **60%, 40%, 80% and 80% of target weight** in the four 2022–2025 folds. A ranking based only on pretest QQQ beta overlaps by **40%, 20%, 60% and 40%**. A fixed equal blend of the beta and liquidity ranks overlaps by **40%, 20%, 60% and 60%**. These are target overlaps, not account returns.

For equal-ten securities, liquidity overlap is **50%, 30%, 70% and 80%**, respectively. Original-five and new-five groups and all **3,618** date/control/allocation comparisons are in the accompanying tables. At each test decision the simple scores are fixed from that fold's first origin, but eligibility can change. Unsupported eligible stocks receive the median supported score. The supported set requires all four characteristics from the previous common-support table, so the liquidity-only control is not based on a pure liquidity-only availability rule.

This suggests liquidity is a useful competing description of part of the persistent basket, with substantial year-to-year variation. It does not show that the model learned liquidity, that the two portfolios earn similar returns, or that a simple liquidity portfolio would replicate the account. The controls were chosen after earlier associations were inspected; validation selected checkpoints, the history is repeatedly examined, and seed groups share market history. Training Hpred and the original numerical and financial gates remain unresolved.

The [protocol](../VALIDATION_SIMPLE_STYLE_OVERLAP_PROTOCOL_20261029.md) and code were fixed as `d338a53` and `3a6a755` before these overlaps. A separate implementation using explicit issuer and security boundary ties verified all **3,618** comparisons, maximum overlap error 5.55e-17. No test labels, returns, account simulation, neural inference or financial fitting occurred.
