# Saved checkpoint tensor and snapshot inspection

Frozen protocol: ../PARAMETER_FORENSICS_PROTOCOL.md. All 80 selected parent and dynamic checkpoints were inspected on CPU without forward calls or optimization. All 80 dynamic unused random-vector controls match reconstructed seeded initialization exactly; state keys and shapes match. This supports initialization reconstruction for the dynamic model, not numerical equivalence of inference on the original hardware. The parent has no equivalent independent unused-vector control.

Across the 40 dynamic fits, both indexed filters are exactly unchanged for every newly eligible and unsupported ID (1,150 ID-fit observations per filter). Supported-ID mean absolute filter changes, averaged across fits, are approximately 0.00496 and 0.00490; sparse-ID changes are 0.00518 and 0.00455. These are descriptive parameter changes, not measured predictive effects. Parent mixer indexed vector update norms are much smaller for newly eligible and unsupported IDs (approximately 0.00002 incoming and 0.00007 outgoing) than supported IDs (approximately 0.124 and 0.115). Parent AdamW weight decay can move coordinates without an informative data gradient, so even a nonzero update does not establish learning or generalization. Counts pool repeated IDs and seeds and are not independent observations.

The four year-specific saved snapshot operators have full rank 156; their condition numbers are about 2.718. One snapshot digest occurs per year across the ten seeds. `W @ W_inv` differs from identity: Frobenius defects range 2.20–2.59 and off-diagonal norms 2.19–2.57. Thus a uniform filter does not mathematically cancel these saved operators. This structural fact does not establish that the snapshot branch contributed to financial results. Fusion softmax coefficients lie between 0.3268 and 0.3382 across branches/fits, but coefficients alone cannot quantify branch influence because activation magnitudes differ.

The first pass in ../execution_batch14_parameters is preserved. It measured change in each parent vector's norm, which misses rotations. This corrected pass additionally measures the L2 norm of the full vector update; the rotation regression test guards this distinction.
