Fixed after seeing batch46's high overall validation/test rank correlations but before calculating this tail diagnostic. Use the same 36 fold/group/family cells, saved predictions, original eligible per-seed percentile ranks and at least five eligible validation and test dates per matched security. For each cell compare the five and ten highest per-security mean ranks in each split; sort descending and break exact ties by ascending stable security ID. Report intersection count, Jaccard, and the fraction of each validation top set that remains above the test median. Record all 72 cells; include matched-ID support and all source file hashes. The universe is restricted retrospectively to IDs eligible in both periods, so it is not an implementable validation-only trading rule. Validation selected checkpoints, test means use full test-year forecasts and are not causal or prospective. No labels, returns, financial fitting, account scoring or checkpoint inference.
