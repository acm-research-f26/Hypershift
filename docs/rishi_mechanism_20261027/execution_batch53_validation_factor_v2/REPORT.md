# Factor comparison of changing and fixed validation preferences

For the ten-seed, issuer-five volatility-target accounts, the retrospective FF5 + momentum + short-reversal + QQQ regression estimates a model-minus-fixed annualized intercept of **+0.70 percentage points**, with a 95% Newey–West interval of **[-6.03, +7.42] pp** at lag 5. At lag 20 the interval is **[-5.67, +7.06] pp**. Without QQQ, the FF7 estimate is +0.55 pp with lag-5 interval [-6.23, +7.32] pp. These wide intervals establish neither a residual advantage nor equivalence.

These regressions compare different realized account paths after modeled costs. The factors are retrospectively sourced, the history has been repeatedly inspected, the slopes are held constant, and industry, nonlinear and time-varying exposures are not fully controlled. The fixed account uses validation forecasts from checkpoints selected on that same validation fold. Consequently the intercept is not proof of causal learned information, a tradable hedge, independent out-of-sample alpha or training-Hpred equivalence. The three seed groups overlap and share the same market history; intervals are unadjusted.

Protocol `7b91daf` and implementation `c28abfa` were frozen before results. The first run reached the output-count assertion but failed because the check incorrectly counted terms; `f66edad` corrected only the expected count and destination, and the original failed output directory was preserved. The completed run contains **36 regressions and 306 coefficient rows**. A separate parser and two-sided Bartlett covariance reconstruction verified all coefficients and standard errors to maximum error **6.95e-14**. No financial fitting, new account, checkpoint intervention, protected scoring or prospective action occurred; the original gates remain unchanged.
