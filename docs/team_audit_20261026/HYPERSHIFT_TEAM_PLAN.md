Initial work is export/replay/attribution, approximately three to five working days of team effort after artifacts arrive, predominantly CPU. This is not a new GPU budget. If the payload fails, spend at most one reconciliation cycle and explicitly decide whether reconstruction has enough value; do not indefinitely repeat artifact requests while calling the audit complete at raw-replay level.

The next experiment document specifies a 252 session diagnostic and a single 504 session confirmation only if power supports that endpoint. Team time should reflect that a small alpha cannot be certified from a few weeks. Existing saved market history supplies mechanism diagnostics, not a new holdout.

Stop splitting the team across loss/k/seed/regime sweeps, standalone architecture ports, and repeated polishing of selected Sharpe charts. Keep one reusable interface and one frozen hypothesis. A result that supports a simple transparent control is a useful outcome; a complete mechanistic negative result can support publication.
