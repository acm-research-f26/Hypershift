# Strategy pivot — WP-A minimal viable strategy + WP-B new-data plan — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build one simple, predeclared, cost-realistic strategy candidate from existing price data, together with its benchmark, factor attribution and decision rules. Explore it once on 2016–2023, freeze it, score it once on a pseudo-holdout, and write a prospective paper-trading spec. Then plan the highest-value new-data study (WP-B) and deliver decisions A–G.

**Architecture:** New package `src/hypershift/strategy/`:
- `signals.py`: momentum, low-volatility and residual-reversal signals, plus their composite;
- `engine.py`: long-only and long-short portfolio engine with drift, next-open or next-close execution, costs, borrow and buffers;
- `factors.py`: Fama–French daily factor loader and HAC attribution.

Scripts `scripts/strategy_*.py` write to `docs/strategy_20261022/`. The existing `fbaudit/book.py` and `diag2.residual_reversal` are reused where they fit.

**Tech Stack:** numpy, scipy, existing panel files. Ken French daily factors (free; downloaded to `data/factors/`, git-ignored).

**Spec:** user prompt "HyperShift — Pivot From Architecture Research to Building a Profitable Trading Strategy". An abridged copy is saved as `docs/strategy_20261022/REQUEST.md`.

### Predeclared candidate and rules (fixed before any number is computed)

**Primary candidate PRICE3-LO** (long-only, monthly):

- **Signals at the close of the last trading day of month m−1:**
  - MOM = P(t−21) / P(t−252) − 1;
  - LOWVOL = −std of the daily returns over the last 252 days;
  - RR21 = −(21-day return − β·EW-market 21-day return, sector-demeaned) / vol_60, using the existing `diag2.residual_reversal` definition with vol_60 computed from returns.

  Each signal is z-scored across eligible stocks and clipped at ±3. **Composite** = mean of the available z-scores (at least 2 required).
- **Portfolio.** Equal-weight long of the top 20% of eligible stocks by composite. **Buffer:** a held name stays while it remains in the top 40%; the rest is filled from the best-ranked names.
- **Execution.** Trade at the **open** of the first trading day of month m. Weights drift between rebalances.
- **Benchmark.** An equal-weight portfolio of all eligible stocks, rebalanced on the same days, same execution and same cost model.
- **Costs:**
  - base **10 bp** per unit of one-way traded notional/NAV (spread + fees + impact for large caps, deliberately conservative);
  - sensitivities 5, 20 and 30 bp.

**Secondary candidate PRICE3-LS** (hedged):
- long the top 20% / short the bottom 20% within each sector, 0.5 gross per leg;
- beta-hedged to zero ex ante with the equal-weight basket;
- buffer: exit at the 40% band;
- same execution and costs, plus **borrow 50 bp/yr** on the short gross, accrued daily;
- cash earns nothing (conservative; the long-short book is self-financing).

**Comparators (context only, not selected among):**
- MOM-LO, LOWVOL-LO and RR21-LO, built the same way;
- the EW benchmark.

**Metrics** (defined in `engine.py` / `factors.py`):
- **LO:** daily active return = LO net − benchmark net. Report annualised mean, volatility, IR = mean/std·√252, max drawdown of the cumulative active return, and per-year active return.
- **LS:** net Sharpe.
- **Both:** turnover (one-way traded/NAV per year) and cost drag.
- **Attribution:** daily OLS of the active (or LS) return on FF5 + MOM + ST_Rev with Newey–West (10 lags). Report the annualised alpha with its t-statistic, and the loadings.
- **Uncertainty:** stationary-bootstrap CIs (block 21 days, B = 2000).

**Exploration decision rule (GO to freeze + paper trading):** all of the following, for PRICE3-LO at 10 bp, open execution:
1. active IR ≥ 0.30;
2. FF6+STREV alpha of the active return ≥ 0 (point estimate);
3. IR > 0 at 20 bp;
4. worst calendar-year active return > −10%;
5. turnover < 300% per year.

Otherwise: **STOP** the price-only candidate (record the reason under the spec's stopping rules). PRICE3-LS: report only; GO if net Sharpe ≥ 0.5 at 10 bp with alpha ≥ 0.

**Pseudo-holdout rule.** Score once and report descriptively. "Consistent" if the active IR is > 0 and the alpha is not below −2% per year; it is not used as confirmation.

## Review Focus

1. **Next-open execution.** A close-to-close jump on the signal day must not be captured (`test_open_execution_no_lookahead`).
2. **Benchmark costs and drift.** The benchmark must be treated like the strategy, so the active return is not inflated by a costless benchmark (`test_benchmark_costed`).
3. **Stocks missing on the rebalance day** (no open price). Weight is kept and not traded; no NaN reaches NAV (`test_engine_missing_open`).
4. **Borrow accrual** only on short gross, at rate/252 per day (`test_borrow_accrual`).
5. **Factor-file date alignment.** Mismatched dates are dropped, and percent units are converted (`test_ff_loader_units`).
