# A13 — v1-LF mask discrepancy and paired economics (closure review)

## Part 1: v1-LF eligibility-mask discrepancy (dev emulation)

v1-LF marks a stock-day ineligible when its 20-day window lacks an unadjusted close. Before this fix, `make_leakfree` left `fb.neutral` as `load_range` computed it with the **pre-LF** mask. Dropped stocks therefore still entered the equal-weight market mean and the sector demeaning of the evaluation target. The fix recomputes `neutral` with the post-LF mask, exactly as `load_range` does (regression test `test_lf_neutral_uses_post_lf_mask`).

Emulation on dev: the audit's unadjusted download is used as the "raw" input. Scoring uses the leak-free residual LightGBM on the post-LF mask with both target versions. Generated by `scripts/closure_lfmask.py`.
