## (c) Daily RankIC variability vs the pure sampling floor

If the true daily IC were constant, a cross-sectional Spearman over n stocks would have SD ≈ 1/√(n−1). Excess SD is day-to-day variation of the true cross-sectional IC (factor/regime variation), which more stocks cannot remove.
