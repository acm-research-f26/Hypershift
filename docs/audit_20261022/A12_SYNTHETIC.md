# A12 — Synthetic validation: can the evaluation separate style-only from incremental information? (M4)

**Synthetic panel.** 400 stocks, 10 sectors, 750 training and 500 evaluation dates.
- 4 persistent style characteristics (AR(1) 0.98) and 6 other features (AR(1) 0.5).
- **Returns (scenario S):** a nonlinear function of the styles with interactions, tanh(s1·s2) + (s3²−1)·sign(s4) + sector-specific slope · s4, standardised, plus noise (SD 10).
- **Scenario I:** S plus a planted incremental term 0.15 × x1, where x1 is a non-style feature.

**Learner.** Matched LightGBM, 50 rounds, seed 7, trained on the date-demeaned return. `full` = all 10 features + sector one-hot; `style` = the 4 styles + sector one-hot.

**Metrics:**
- **raw** = RankIC vs the date-demeaned return;
- **LIN / NL** = RankIC vs the return residualised per date on sector + linear styles / + style quintile dummies;
- **increment** = full − style on raw;
- **encompass** = full residualised on style (M3).

Each cell gives the pooled value with a stationary-bootstrap 95% CI over 5 blocks of 100 evaluation dates, for replicates (0, 1, 2). Generated by `scripts/closure_synth.py`.

## M4 verdict

- Residualised metrics reward the style-only model when returns are style-only (S: style LIN and NL CI > 0 in all reps): **yes**.
- Matched increment gives no false increment in S (CI includes 0 in all reps): **no**; detects the planted increment in I (CI > 0 in all reps): **no**.
- Encompassing: no false positive in S: **no**; detects I: **yes**.
- **PASS** (matched increment discriminates and residualised metrics are shown to fail): **FAIL**.

## Follow-up (ledgered): dimension-matched conditional-permutation control

Why the naive matched increment failed: in S, adding 6 uninformative columns *lowers* the 50-round model's score (dilution/capacity), so full − style is negative even with no information. In I it stays negative, so the planted term is outweighed. Encompassing is positive in S because two learners capture different parts of the same nonlinear style signal. Neither is a valid test.

Control: `full_perm` has the same 10 inputs, but the 6 non-style columns are permuted jointly within date inside 20 bins of the style-only model's prediction (`matched.permute_within_bins`). Increment = full − full_perm (raw RankIC). This matches input dimension and learner capacity and keeps the extra columns' association with style; only stock-specific information is destroyed.

## Overall reading (closure review)

1. **The residualised metrics (LIN, NL) are invalid for "beyond style".** A style-only model keeps most of its score after residualisation when returns are nonlinear in styles. This is verified.
2. **The matched LightGBM increment is invalid with this learner, and so are encompassing and the conditional-permutation control.**
   - **The cause is learner power, not the test design alone.** The FB LightGBM configuration (15 leaves, min_child 1000, lr 0.05, 50 rounds) does not exploit an incremental linear signal of standalone IC about 0.05 (increment −0.004). At 300 rounds it captures little (+0.005).
   - **Ridge finds the planted signal**, but it cannot model the nonlinear style signal.
   - **Consequence:** with this learner, "full ≈ style" on real data says nothing about whether the extra features carry information.
3. **What a valid test of question B needs** (not run here; doing so would be a new method study):
   - a style baseline flexible enough to absorb nonlinear style effects;
   - plus an incremental component with demonstrated power on synthetic data, e.g. a conditional-predictive-value regression of outcome ranks on the out-of-sample style-model prediction and the candidate features, validated first on S/I scenarios like these.
