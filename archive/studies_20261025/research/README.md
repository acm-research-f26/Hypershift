# Archived experiment sources

These grouped sources belong to earlier fixed-cohort, pooled, random-trial,
exchange-geometry or retired-universe experiments. Their original code bytes
are preserved. They are omitted from normal launcher listings and test discovery.

Use `python -m hypershift --archived list archive` from the repository root to
find them. The [archive guide](../README.md) explains opt-in execution and the
limits of rerunning historical studies after their local inputs were archived.
Shared code still needed by active NASDAQ models remains in
[research](../../../research/README.md); the new study is in
[latest](../../../latest/README.md).
